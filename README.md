# 📊 Sistema de Gestão de Alunos

## 📋 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de programação em *Python*, manipulação de banco de dados e operações básicas de CRUD (Create, Read, Update e Delete).

---

## 💻 Tecnologias Utilizadas

- Python
- SQLite3

---

## 🛠️ Funcionalidades

- Cadastrar alunos
- Listar alunos
- Editar alunos
- Excluir alunos
